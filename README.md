# Controle de Adiantamentos — Casa Brasilis

App interno do financeiro para controlar pagamentos antecipados a fornecedores e a baixa pelas notas fiscais.

- Acesso: somente usuários liberados pelo coordenador financeiro.
- Os dados ficam no banco (Supabase), protegidos por login e permissões. Este repositório contém apenas a tela.
